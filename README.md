# 现代战线 MODERN FRONTLINE

一款在浏览器里运行的现代军事题材第一人称射击游戏（原创致敬作品），用 Three.js 写成，**没有用到任何外部美术或音频素材**：所有纹理（包括法线和粗糙度贴图）、模型和音效都由程序实时生成。

## 开发背景

本游戏全程仅通过 **Claude Opus 5.5** 的**一轮对话**生成完成。

## 运行方法

游戏使用 ES Module，必须通过本地 HTTP 服务器打开，直接双击 html 文件打不开。项目自带一个零依赖的 Node 服务器：

```bash
node server.mjs          # 默认端口 8080
node server.mjs 8888     # 也可以指定端口
```

或者：

```bash
npm start
```

然后在浏览器打开 `http://localhost:8080`。需要 Node.js（建议 18 及以上），服务器没有任何第三方依赖，无需先执行 `npm install`。

推荐使用最新版 Chrome 或 Edge，并开启独立显卡。如果帧数偏低，可以在「设置」里调低画面质量。

## 局域网联机（真人 vs 真人）

主菜单点「局域网联机」，和其他玩家在同一个局域网内进行团队死斗 / 占领 / 自由混战。页面**必须**由 `server.mjs` 提供（双击打开或用其他静态服务器都不行），因为联机走同一台服务器上的 WebSocket。启动方式与上面的「运行方法」相同：

```bash
node server.mjs        # 默认端口 8080，也可以 node server.mjs 8888
```

启动后终端会打印「局域网访问」地址（如 `http://192.168.1.5:8080`）：

1. 每位玩家在浏览器打开该地址 → 主菜单「局域网联机」→ 输入昵称 → 进大厅
2. 一个人创建房间（房主），其他人从房间列表点「加入」（同一网络内会自动列出所有房间）
3. 房主选择模式 / 地图 / 时长后点「开始对局」，所有房员同时部署

特性与规则：
- 支持 TDM / 占领 / FFA，最多 16 人；每位玩家使用自己的配装、Perk 和连杀奖励
- 击杀、手雷、掉落武器、连杀奖励、比分和结算在各端自动同步；只有**受害者**结算自己的伤害，因此打击感是即时的，作弊空间也小
- 房主退出后自动迁移房主；对局结算后由房主点「再来一局」重新编队开赛
- 服务器零依赖（纯 Node.js，`npm start`），只做房间管理和中继，不跑任何游戏逻辑

## 内容

### 战役：行动代号「午夜清道夫」
夜间渗透卡尔达什边境，和布雷克上尉、狙击手渡鸦组成三人小队，共 7 个阶段：
1. 夜视仪渗透（按 N 切换夜视仪）
2. 清除前哨站。可以选择潜行：敌人有「警觉值」，发现你需要一段时间；蹲伏和使用消音武器都更难被发现，被察觉后整组敌人会一起警戒
3. 穿越村庄
4. 突入大院，逐屋清理，击毙高价值目标「铁蝎」
5. 按住 F 下载情报
6. 坚守 90 秒，抵挡三波敌方增援（包括皮卡运兵）
7. 东门打开，乘直升机撤离

其他：设有检查点，死亡后按空格从检查点重来；可选三档难度，并记录最佳通关时间。

### 多人对战（对战 AI）
- **模式**：团队死斗、占领（A/B/C 三个据点）、自由混战
- **地图**：
  - 沙丘镇：沙漠，白天
  - 寒霜炼厂：暴风雪
  - 霓虹街区：雨夜都市
  - 货柜场：黄昏港口
  - 边境机场：戈壁黎明，400×400 的大型机场，跑道、航站楼、机库、油库与货运区构成多条进攻路线
- **AI**：分三档难度，会寻路、找掩体、投雷、夺点，也会使用连杀奖励
- **Perk**：3 个栏位共 12 项，包括双倍时间、拾荒者、爆破专家、冷血、强硬路线、火力过载、幽灵、速愈、快手、振奋、静步、高度警觉
- **连杀奖励**：侦察无人机、集束空袭（手动标记目标）、哨戒机枪、武装直升机、白磷弹；每次从中选 3 项
- **计分**：有击杀奖章（爆头、远距离、双杀、三杀、首杀）、助攻，以及经验值和等级系统

### 射击训练场
没有敌人，只有靶子，用来熟悉枪械、练枪和测试配装：
- **固定靶**：10 个红白靶分布在 12–37 米，站姿、不同距离和角度都有
- **移动靶**：3 条轨道上的靶子横向往返，可选慢速 / 标准 / 高速
- 命中记分：靶面 50 分、内环 100 分、靶心 150 分（靶心命中按爆头结算伤害，伤害数字会更高）；靶子有耐久，累计伤害打空后才向前倒下，短暂延迟后重新立起
- HUD 实时显示得分、命中率、击倒数与最高分，Tab 记分板可查看详细统计，最高分保存在本地
- 射击位旁有弹药箱：靠近按 F 补满弹药与装备，不用担心打空

### 武器与枪匠
- **25 把武器**：
  - 突击步枪：M4A1、AK-47、SCAR-H、QBZ-95-1、QBZ-191、QBZ-03、G36C、AUG A3
  - 冲锋枪：MP5、Vector、P90、MP7、QCW-05
  - 轻机枪：PKM、QBB-95-1、M249
  - 霰弹枪：M870
  - 射手步枪：SKS、QBU-88、SVD
  - 狙击步枪：L115A3
  - 手枪：M1911、.357 左轮、QSZ-92
  - 火箭筒：RPG-7
- **枪匠**：8 个配件栏位，每把枪最多装 5 个配件。配件对属性的正负影响会实时对比显示。枪械 3D 模型可以拖拽旋转和缩放，有 7 种迷彩（含黄金）
- **配装**：5 套自定义配装，可以随时改名，也可以在对局中途更换（下次部署时生效）；每套配装可单独选择头盔与防弹衣，防弹衣为可选项（轻甲 / 制式 / 重型，也可以不穿）；头盔降低爆头伤害、防弹衣降低躯干伤害，越重则机动性越低
- **装备**：
  - 致命装备：破片手雷（可烹饪）、粘性炸弹、燃烧瓶
  - 战术装备：闪光弹、烟雾弹、兴奋剂

### 画面
- 基于物理的材质（PBR），带实时阴影，使用 ACES 色调映射，后处理包括泛光、调色和 FXAA 抗锯齿
- 场景道具带细节建模：木箱框架与斜撑、油桶箍与加注口、集装箱波纹与锁杆、车辆保险杠/格栅/轮毂、灯柱灯罩与检修门
- 投掷物与掉落武器有独立模型：手雷握片与拉环、闪光弹/烟雾弹色带、火箭弹尾翼，掉落武器会缓慢自转
- 动作与界面动画：第三人称呼吸/步伐/受击回弹，第一人称落地缓冲与开镜呼吸，菜单入场、卡片悬停与 HUD 过渡
- 天气：沙尘、暴雪、降雨，以及动态天空
- 特殊视觉效果：夜视仪、热成像瞄具，还有受伤、闪光致盲和白磷弹的屏幕效果
- 伤害数字：所有模式命中时在弹着点显示伤害值（爆头高亮、击杀变红），可在「设置」里关闭

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| Shift | 冲刺 |
| C / Ctrl | 蹲伏；冲刺中按下为滑铲 |
| 空格 | 跳跃 |
| 鼠标左键 / 右键 | 射击 / 瞄准 |
| R | 换弹 |
| 1 / 2 / 滚轮 | 切换武器 |
| V | 近战 |
| G | 致命装备（按住可烹饪手雷） |
| Q | 战术装备 |
| F | 互动 / 拾取武器 |
| N | 夜视仪（仅战役） |
| 3 / 4 / 5 | 使用连杀奖励 |
| Tab | 记分板 |
| Esc | 暂停 |

## 目录结构

```

lib/                      Three.js r169（本地文件，不依赖 CDN）
js/main.js                入口：渲染管线、主循环、输入处理
js/menu.js                菜单：主菜单、大厅、配装、枪匠、设置、联机房间
js/net.js / netplayer.js / netmatch.js   联机：连接与房间、远端玩家实体、联机对局
js/campaign.js            战役流程
js/training.js            射击训练场：固定靶、移动靶与训练计分
js/mp.js                  多人模式、连杀奖励（哨戒机枪、直升机等）
js/player.js / weapons.js 玩家控制器、武器系统、第一人称视图模型
js/ai.js                  AI（寻路、感知、战术行为）
js/world.js / maps.js     关卡构建工具和 6 张地图
js/textures.js / materials.js  程序化纹理与材质
js/gunmodel.js / soldier.js    枪械模型与士兵模型
js/effects.js / combat.js / audio.js / hud.js  特效、弹道判定、合成音效、HUD
```
